# 图片内标注工作区部署记录

2026-10-16，101 已部署 `20261016-canvas-v2`，替换此前 `20261016-right-drag-v1` 页面版本。

## 操作与排版

- 页面保留左侧图库与大图，取消常驻右侧分类栏。图片状态、详细分类、备注与关联信息按需打开。
- 右键拖出问题范围，或点击已有框，在图片内打开不透明浅色选择面板；问题点在左、责任在右。
- 已有问题默认选中，按钮顺序稳定。当前 21 个问题在较短桌面使用三小列，长桌面使用两小列；两大列始终为问题点和责任。
- 责任优先显示其他选项，标准自动责任作为文字放在右列下方。标准定责问题仍按既有规则处理；共性问题允许责任多选或待核。
- `Space` 确认当前框并继续下一处，`Enter` 保存整张后进入下一张。缺少必选责任时留在原处，保存失败也不会切换图片。
- `Esc` 取消当前框的未确认修改；输入备注时空格作为文字输入。选中按钮采用实蓝底白字，框名具有实色底条。
- 上一张、撤销、图片状态、图片信息与保存操作固定在底部。保留原详细分类及批量处理入口。

此次没有替换模型或修改训练筛选规则、自动学习频率。原分类与人工框保留，新增标注延续原有原子追加和冲突检查机制。

## 验证

- 50 项相关 Python 测试通过，覆盖分类、位置标注与候选框保存。
- 前端语法、责任规则、图片筛选、框坐标、框选编辑、空格续标和 `test_workspace_ui.cjs` 工作区测试通过。
- 实际浏览器使用独立测试数据库及真实 NAS 来源图片完成框选、问题与责任选择、空格继续、Enter 保存的流程验证；测试未写入正式标签。
- 在 1366×768 视口检查，整页与框选浮层没有纵向滚动；当前问题按钮完整显示。
- 发布后服务可用，线上静态文件与发布包一致。
