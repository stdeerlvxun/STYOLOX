# 自动框待审核

## 操作

1. 选择“自动框 · 待审核”，虚线是机器建议。
2. 点击“采用建议框”，再拖动框、拖四角缩放；可改类别、删除、撤销或补画遗漏。
3. 点击中央上方“保存补标并下一张”。采用和自动暂存仍不等于人工确认。
4. 未采用的建议可直接拒绝，队列切换下一张。原问题点、责任、备注保持独立。
