# 右键快速框选与后台静默部署

2026-10-16，101 已上线 `20261016-right-drag-v1`。

## 操作流程

1. 在照片内按住鼠标右键拖出范围，松开后在框旁弹出问题点。
2. 默认选择本图已有的问题点；可以改选，已有多个问题时可自行确定当前框的问题。
3. 责任按既定标准带出：生产、原材料采用已有规则；共性问题手动多选，无法确定时选待核。
4. 同图可以继续增加多个框；已有自动框可拖动、缩放和改类。
5. `Enter` 确认整张图片，保存成功后才进入下一张；保存失败留在当前图片并保留编辑。

支持 `Esc` 取消、`Delete` 删除选中框和 `Ctrl+Z` 撤销。
工艺孔、正常结构可记录为局部纠错，局部正常不代表整张图片正常。
编辑暂存不等于人工确认，未确认机器建议与草稿不会作为人工框进入训练。

快速框选确认按用户选择追加问题点和责任，不删除原有分类；原人工框保留。
模型、训练图片筛选规则、20 张有效确认纠错的自动学习频率均未修改。

## 后台静默

计划任务 `STYOLOX-ReviewedCorrectionLearning` 继续启用，每 5 分钟检查，重复实例策略为 `IgnoreNew`。
任务改用基础运行时真实 `pythonw.exe`，避免虚拟环境 `pythonw.exe` 启动器转而创建控制台 `python.exe`。
worker 的 Python、SSH、SCP 和 `nvidia-smi` 子进程统一使用 Windows `CREATE_NO_WINDOW` 与隐藏启动信息，
仍采用参数数组、`shell=False`；非 Windows 平台不传 Windows 专用参数。
新入口只读检查退出码为 0，真实父进程和子进程的控制台句柄检查均为 0。
正在运行的旧 worker 未被终止，完整静默配置从下一次启动生效。
