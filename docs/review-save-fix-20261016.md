# 错例复核保存流程修复

2026-10-16 15:25 已部署到 101，源分类项目提交 `97742fc`。

原因：右侧确认会写入分类和确认历史，但原来只有上方位置补标确认会更新错例复核状态。
因此用户已经复核的 90 张图片仍显示为待复核，看起来没有保存。

## 修改

- 在错例队列中，右侧“保存分类并完成复核”将分类和复核状态放在同一个数据库事务。
- 撤销恢复原分类编辑及复核状态；无位置框时不生成补标记录。
- 页面 Enter 默认执行分类流程，补标控件内 Enter 才执行补标确认。
- 空框不显示“位置补标已保存”；保存失败保留框并允许重试。
- 最后一张保存后明确显示“本轮错例复核已完成，结果已保存”。
