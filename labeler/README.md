## 打开与分类

部署到 101 后，打开 http://192.168.0.101:8878 。桌面“售后图片分类”同步指向此地址。
本机模式仍可运行本目录的“启动分类工具.cmd”；迁移完成后该入口自动打开服务器。
浏览器地址为 http://127.0.0.1:8878 。关闭浏览器后可以再次通过桌面入口打开。
首次扫描会显示“已索引”进度，已找到的图片可立即分类。

1. 选择“未分类”，查看中间大图。
2. 选择右侧破损类型和责任，两组均可多选。“新增标签”展开后可以添加。
3. 按 Enter 或“保存并下一张”，确认标签并继续。
4. 在左侧展开“按破损和责任筛选”，直接查看符合条件的原图。
5. 导出当前筛选为 JSON 或 CSV，供后续数据准备使用。暂存请先确认后再导出。

责任无法判断时保留“待核”，不会根据图片自动推定责任。
没有破损、看不清、无关图片可以直接选择相应图片状态。
“确认无可见破损”与破损标签互斥。

## 快捷键与批量操作

- 1～5：前五个破损标签。
- Shift＋1～5：前五个责任标签。
- Enter：确认并下一张。
- 左右方向键：浏览；Ctrl＋Z：撤销上次确认。
- 滚轮缩放、拖动画布、旋转；这些操作不修改原图。
- 勾选缩略图左上角复选框，再点“批量追加标签”，确认后把右侧当前标签追加到所选图片。

批量状态与既有标签冲突时，整批操作会停止，不清空原标签。
标签选择后约 350ms 自动暂存，退出重开恢复。确认和切图期间会暂时锁定编辑，
防止网络响应期间的新输入丢失。保存失败会保留当前图片并提示重试。
撤销后恢复先前确认记录，刚才的选择保留为暂存，便于修改。
输入备注和标签名称时快捷键不会抢走正常输入。

## 筛选与加载

两组筛选同时满足；一组勾选多个标签时满足其中任意一个即可。
默认按售后单申报日期从近到远，先显示近期未分类图片。申报日期缺失时使用来源创建时间，
其次归档月份，最后才是文件时间；导出包含日期及其来源，避免把补采时间误认为售后发生时间。
“责任待核 / 看不清”筛选针对已经确认的标签。暂存仍属于未分类。
重新扫描只增量更新图片索引，已有标签保留；新下载图片可点“重新扫描”发现。
NAS 暂时断开时，标签保留，恢复连接后可重试或重新扫描。

文件列表每次读取 40 条，缩略图只渲染视口及附近区域，原图按需读取。
后台最多两个图片工作线程，当前大图优先，顺序预读后续两张。
当前预览超过 1.5 秒时暂停相邻预读；切换目录或筛选条件会取消旧任务。
本地只缓存压缩预览，约 256MB 上限并定期清理，不保存整批原始图片副本。
“原始清晰度”或放大查看细节时才读取原始分辨率。

## 模型问题点建议（101，0.4.0）

打开未分类、没有已有草稿的图片，右侧会显示“模型建议 · 待确认”。

也可点“采用全部建议”后按图删改、补充问题点，再按原流程选择责任并按 Enter 保存。
采用建议只追加问题点，不清空当前选择或备注；模型自身不输出责任，既有人工标签业务规则继续生效。
没有推荐不代表没有问题，仍应人工看图。建议可能多报，不能据此自动定责或自动确认。

已有分类与已有草稿跳过推荐。每次请求和推理结束再次核对状态；
采用后的暂存、确认还会检查分类是否已存在及草稿指纹，遇到并发人工编辑则拒绝覆盖。
预测保存在独立 `recommendations.sqlite3`，不写 labels/drafts/history，不进入训练标签导出。
前台按需预测优先；启用待审核队列后，后台逐张处理近期未分类图片，共享单个推理线程和 CPU 2 个计算线程。
缓存绑定模型版本和源文件标识，模型或图片变化后重新计算；失败时仍可手动分类和重试。

101 使用 `/opt/after-sales-image-labeler/models/recall-v3` 的 ONNX 模型，

## 疑似无关图片辅助建议

经用户单独确认，已确认的“无关图片”仅用于独立辅助筛选器。
问题点模型的 `problem_points_only_v2` 规则保持不变，状态图片仍不能进入问题点训练。
辅助筛选器也排除草稿、看不清、正常、状态与问题点冲突及完全重复图片。
相关对照来自已确认的问题图片，按售后单、订单和重复图组隔离验证。

命中保守条件时，在原固定建议区增加“疑似无关图片”，原问题点建议继续显示。
点击该按钮仅选择状态，仍需按 Enter 确认；“采用全部问题点”不会采用状态建议。
已有问题点、其他状态、已有分类或草稿不会被这条建议清空或覆盖。
默认建议模式不自动跳过；经用户再次确认启用 `--unrelated-review` 后，按下述待审核队列处理。没有无关建议也不表示图片一定相关。

左侧“已标无关图片 / 复核”可直接查看已确认的无关图片，有误标时按原人工流程修改。
未通过人工确认的模型建议不属于训练标签。训练中发现的可疑标签只输出复核清单，不自动纠正。
