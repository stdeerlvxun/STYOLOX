# 问题位置粗框候选

`generate_box_proposals.py` 用当前上线的 ConvNeXt 六视图问题分类检查点做弱定位，
仅生成独立待审核 JSON；没有训练检测器、写入标签数据库、复制原图或替换 101 模型。

```powershell
& 'D:\视觉检测工作区\envs\yolox\Scripts\python.exe' generate_box_proposals.py `
  --snapshot 'D:\视觉检测工作区\runs\20261016-auto-boxes\source\labels.sqlite3' `
  --run 'D:\视觉检测工作区\runs\20261016-problem-only-120454\recall-trained-v3-fixed-cutoff' `
  --output 'D:\视觉检测工作区\runs\新的运行目录\box-proposals.json'
```

可先加 `--limit 8 --preview-dir 本地检查目录` 生成少量叠图；预览只是本地 QA 图片，
不能作为源图或训练标签。已有输出不会覆盖；输入快照必须是 SQLite 一致性备份。

## 输入和保存边界

- 仅当前目录、人工确认有问题点的图片，按售后日期从近到远。
- 任意图片状态按钮（normal / unclear / unrelated）、分类草稿、已有人工位置文档均排除。
- 类别只取人工已经确认的问题点；上线旧模型未包含的类别明确弃权。
- 原标签的 SHA256 对精确原始 JSON 文本计算；不重新序列化后计算。
- 原图只读；校验快照已有 SHA256，并另存实际 SHA256 与 EXIF 转正后的像素尺寸。
- 坐标为 `exif_transposed_normalized_xywh`，与分类工具人工框一致。
- 候选 `origin=model`、`requires_human_review=true`，审核前禁止纳入训练。
- 产物包含内部文件路径和标注指纹，只放运行目录，不提交公共仓库。

## 方法与明确限制

沿用原检查点、原分类阈值、原六视图与归一化。分别取 ConvNeXt 两层的 Grad-CAM，
要求位置激活有交集，再做局部信息遮挡检查：抹掉候选区域后目标类别分数须下降。
这只证明分类模型依赖该区域，**不能证明那里就是问题**；分类模型仍可能依赖背景、
包装文字、水印及其他相关物体。

整体弥散、大面积、图边界及相机水印常见角落区域一律保守弃权；
这也会漏掉真实的边缘或角落问题。低分、无激活、不支持遮挡验证或未学习类别均保留原因。
最多每类别两个候选；没有候选不等于正常，也不等于已复核。

`score` 是原图问题分类分数，不是定位置信度；`ablation_score_drop` 是遮挡后的模型分数下降，
也不是缺陷概率。没有位置真值，不能报告定位准确率、找回数或漏检数。

前端必须允许拖动、缩放、删除、补框和改类别，并由用户明确保存确认。
机器候选必须与已有人工标签和人工位置文档分开保存；导入时再次核验原标签指纹与源图，
人工已开始补框则跳过候选，不得覆盖。
